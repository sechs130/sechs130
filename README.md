## Hi, I'm Silvio 👋

A small window into the things I spend my time on.

Applied AI & ML, based in Berlin. M.Sc. Computer Science.
I gravitate towards the unglamorous half of machine learning — getting things to
actually run on real data, inside real memory budgets, fast enough to be useful.

**What I've been working on**

- My master's thesis: semantic segmentation of large-scale LiDAR point clouds with
  [Pointcept](https://github.com/Pointcept/Pointcept). Mostly a study in chunking
  strategies, merge logic, and what each of them costs in runtime and memory.
- Retrieval-augmented generation, end to end — ingestion, chunking, retrieval
  evaluation, serving.
- Whatever data happens to be lying around: geospatial, sensor, tabular.

**Usual tools**
